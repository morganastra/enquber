Performance
	Startup theme-icon lookups are done: MainWindow now probes the active icon
	theme once and falls back to the bundled glyphs for the whole set when the
	theme has no action icons, and the never-displayed quit/help action icons
	were dropped. Fully-settled startup is now faster than kcalc on Xvfb; see
	doc/startup-performance.md.
